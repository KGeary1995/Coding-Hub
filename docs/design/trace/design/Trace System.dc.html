rationale · signature
The scope strip
Each agent is a channel on an instrument. A 40 px strip under the tile name plots the agent's token throughput over the last 120 seconds, read from the CLI's usage events. The shape of the trace encodes state, so you can tell working (busy noise), waiting (held high), finished (decay to flat), failed (cut off) and near-limit (clipping the dashed rail) from across the room, before reading a word. Glyph, word and colour repeat the same state, so none of the three is load-bearing alone. Engine identity is the channel colour, the way CH1 and CH2 are coloured on a bench scope: it borrows from instruments, not from either vendor's brand.
rationale · navigation
Three tiers, one status line
The top bar holds the daily loop as tabs: Workspace, Changes, Projects. The Insight menu holds Usage, History, Tasks, Verification, Design and Coaching, one click away and labelled with the current view when open. Agent setup is a separate button that opens one area for Accounts, Memory, Rules, MCP, Skills and Settings. Workflow center is removed: Recovery moves into the failed tile (Retry, Open log), Search and Templates into the command menu, Support into Help. The bottom bar is the only status layer: per-channel state and rate, project and branch, today's tokens and cost, alerts.

Accessibility
Text on #0b1010: fg #d8e3df 14.6:1 · dim #879692 6.2:1 · faint #6f807b 4.5:1 (labels only, ≥ 11 px mono). Every state colour clears 4.5:1 on the terminal surface; solid chips use #0b1010 text. Focus: 2 px #eef4f1 outline, 2 px offset, on every control and tile. Tiles are focus targets; Enter focuses the terminal, Esc returns focus to the tile. Keys: Alt 1–4 channels, G then letter for views, Y / N approve and deny on the focused tile, R retry, H handoff. 125% zoom: top bar search collapses to an icon below 1440 px effective width; grid tiles drop to columns.
